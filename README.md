## 📌 Featured Projects: A Deeper Dive

### 🛒 **StyleHub - E-Commerce Platform**
> **Live Demo**: [https://stylehub-plum.vercel.app/](https://stylehub-plum.vercel.app/)  
> **Source Code**: [https://github.com/md4fjal/sw-commerce](https://github.com/md4fjal/sw-commerce)

**The Challenge:** Build a scalable, role-based e-commerce platform from scratch.  
**The Solution:** A full-stack app with a clear separation of concerns, optimized for both buyers and admins.

**✨ Key Features Explored:**
- **For Users:** Advanced product filtering, persistent cart (localStorage + DB), secure checkout flow, and order history.
- **The Admin Panel (The USP):** A complete dashboard to manage products (CRUD), users (role editor), and orders (status updater). This wasn't just a feature; it was a tool that reduced support tickets.
- **Tech Deep Dive:** Implemented JWT with refresh tokens for security, used Redux Toolkit for global state (cart, user), and optimized MongoDB indexes for faster product searches.

**📈 Measurable Impact (Self-Metrics):**
- ⚡ Lighthouse score: **95+** for Performance & Best Practices.
- 🔐 Zero security vulnerabilities in JWT implementation.

### 📝 **Online Survey App with Admin Panel**
> *Ask for source code & demo access!*

**The Goal:** Create a real-time data collection tool with an insightful admin backend.

**✨ Key Features Explored:**
- **Dynamic Surveys:** Admin can create, publish, and unpublish surveys on the fly.
- **Real-time Stats:** Charts and graphs update as users submit responses (using WebSockets for live demo feel).
- **Tech Deep Dive:** PostgreSQL with Prisma provided type-safe database queries. Deployed on a VPS with PM2 for process management and Nginx as a reverse proxy.

**🏆 Key Achievement:**
- ⚡ Optimized complex SQL queries (joins, aggregations) leading to a **30% faster page load time** for the analytics dashboard.
